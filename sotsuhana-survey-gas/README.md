# 卒花アンケート回答通知 GAS

フォーム回答があったときに通知メールを送るスクリプトです。元の `notifyNewSurveyResponse` を、以下の要件に合わせて拡張しています。

## 今回の変更点

1. **メール本文**
   - 「ご新郎様氏名(カタカナ)」「ご新婦様氏名(カタカナ)」を本文の一番上に表示
   - 同じ質問が重複して出てくる場合は1回だけ表示
   - 回答が空欄の質問は本文に載せない
2. **申し込み店舗への自動送信**
   - フォームの「申し込み店舗」の回答をもとに、店舗マスタ（裏のスプレッドシート）からその店舗のメールアドレスを検索し、固定宛先に加えて自動で送信する
3. **店舗名の選択肢の同期**
   - 店舗マスタの店舗名一覧を、アンケートフォームの「申し込み店舗」の選択肢へワンクリック／自動で反映できる

## セットアップ手順

### 1. スクリプトプロパティを設定する

回答用スプレッドシートに紐づく Apps Script エディタを開き、「プロジェクトの設定」→「スクリプト プロパティ」に以下を登録してください。

| プロパティ名 | 値 |
| --- | --- |
| `MASTER_SS_ID` | 店舗マスタを管理する「裏」のスプレッドシートのID（URLの `/d/` と `/edit` の間の文字列） |
| `FORM_ID` | アンケートフォームのID（店舗選択肢の自動同期を使う場合のみ必須。フォーム編集画面URLの `/d/` と `/edit` の間の文字列） |

### 2. 裏のスプレッドシートに店舗マスタを作る

`MASTER_SS_ID` で指定したスプレッドシートに、**「店舗マスタ」という名前のシート**を作成し、以下のように入力してください。

| A列（店舗名） | B列（メールアドレス） |
| --- | --- |
| 店舗名 | メールアドレス |
| 新宿店 | shinjuku@example.com |
| 横浜店 | yokohama@example.com |
| … | … |

- 1行目は見出し行です（そのままでOK）。
- A列の店舗名は、フォームの選択肢に表示したい文言と同じにしてください。

### 3. アンケートフォームに「申し込み店舗」の質問を追加する

- 質問形式は「プルダウン」「ラジオボタン」「チェックボックス」のいずれか
- 質問文は `申し込み店舗`（`Code.gs` の `CONFIG.STORE_QUESTION_TITLE` と一致させる）
- 選択肢は後述の同期機能で自動的に反映されるので、最初は仮の選択肢でOK

### 4. トリガーを登録する（初回のみ）

Apps Script エディタの関数選択で以下を1回ずつ実行してください。

- `setupFormSubmitTrigger` … フォーム送信時に通知メールを送るトリガーを登録
- `setupStoreSyncTrigger` … 店舗マスタの内容を1時間おきにフォームへ自動反映するトリガーを登録

（実行時に権限の承認を求められるので許可してください）

### 5. 手動で同期したいとき

回答用スプレッドシートを開くと「管理メニュー」が追加されるので、そこから「店舗選択肢をフォームに同期」を選ぶといつでも手動同期できます。

## ファイル構成

- `Code.gs` … 本体のスクリプト
- `appsscript.json` … Apps Script のマニフェスト
