- 監査対象: 添付ファイル「診断城戸口.txt」（`<script>` 部分のみ、676行、改行コード CRLF）。本フォルダの `original.txt` は添付ファイルをそのまま複製したもの

## 0. 監査の前提と限界

- 添付ファイルには HTML と CSS が含まれていない。このため、スクリプトが参照する画面部品（`bg-q1`〜`bg-q7`、`bg-result`、`.alt-panel`、`res-consult`、`insta-copy-btn` など）が実際の HTML に存在するかは**確認不能**。
  - なお、リポジトリ内の `wedding-destination-quiz.html` は別系統（作り直し後）の版で、画面部品の名前も処理内容も異なる。今回の監査対象ではない。
- 試験は、スクリプトが参照する画面部品だけを持つ仮の画面を用意して行った。
  - Node 上の簡易な画面の代用（`test/harness.js`）: 総当たり試験と操作試験に使用
  - 実ブラウザ（Chromium）上の仮の HTML（`test/browser.js`）: 実行時エラーの有無を確認
- この作業環境からは `www.his-wedding.com` への接続が遮断されている。このため、リンク先・画像の実在、各撮影地の実際の撮影可否、手配条件は**一切確認できていない**。地域の特徴についての記述は一般的な地理の知識に基づくもので、公式情報による裏付けはない（該当箇所に「未確認」と明記）。
- 総当たり試験は「画面上で選べる回答の組み合わせ」を同じ重みで数えている。実際の利用者の回答の偏りは反映していない。

### 1-1. データ

- `DEST`（7〜51行）: 撮影地40件。各撮影地は表示名、英語名、画像、リンク、推薦文、タグ、主な撮影都市（`subCities`）と、景色・演出の有無を表す真偽値（`chapel`、`starry` など）を持つ。`korea` はコメントアウトされている（12行）。
