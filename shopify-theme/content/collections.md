# コレクション（撮影地）投入用コンテンツ

各コレクションについて、以下をShopify管理画面にそのままコピーしてください。
`custom.features` / `custom.seasons` / `custom.faqs` は metaobject の一覧参照です
（型の作り方は `shopify-theme/README.md` を参照）。画像はプレースホルダーのため、
実写真をアップロードしてから `custom.seasons` の image / `custom.gallery` /
コレクション画像 に差し替えてください。

## ハワイ（Collection handle: `hawaii`）

**Description（コレクション説明）**
```
日本からの直行便でアクセスしやすく、初めての海外フォトウェディングにも選ばれる定番の撮影地です。
```

**custom.lede**
```
ワイキキビーチとダイヤモンドヘッド。常夏の光が織りなす、王道のロケーションで。
```

**custom.features（feature_item ×4）**
1. title: `王道のビーチロケーション` / description: `ワイキキビーチをはじめ、透明度の高い海と青空を背景に撮影できます。`
2. title: `ダイヤモンドヘッドと街並み` / description: `象徴的な景観とレトロなカラハウ通りの街並みで、表情豊かな一枚を残せます。`
3. title: `通年撮影しやすい気候` / description: `年間を通じて温暖で、天候リスクが比較的低いのも安心材料です。`
4. title: `直行便でアクセス良好` / description: `日本各地から直行便があり、渡航負担が少ない撮影地です。`

**custom.seasons（season_card ×4）**
1. title: `4〜6月` / description: `雨が少なく過ごしやすい、狙い目のシーズン。`
2. title: `7〜9月` / description: `最も晴天率が高く、青空を狙うならこの時期。`
3. title: `10〜12月` / description: `日中は温暖。夕方のマジックアワーが美しい季節。`
4. title: `1〜3月` / description: `短時間のスコールに注意しつつ、旅費が抑えやすい時期。`

**custom.faqs（faq_item ×3）**
1. Q: `ハワイは何日程度の滞在が必要ですか？`
   A: `撮影自体は1日で完結しますが、時差調整や体調管理を考慮し、3泊5日以上の滞在をおすすめしています。ハネムーンと合わせて長期滞在される方も多くいらっしゃいます。`
2. Q: `雨季でも撮影できますか？`
   A: `ハワイのスコールは短時間で止むことが多く、撮影スケジュールに屋内・屋外の両方を組み込むことでリスクを最小限にしています。荒天時は撮影日の振替にも対応します。`
3. Q: `ビザは必要ですか？`
   A: `日本国籍の方は電子渡航認証システム（ESTA）の事前申請で渡航可能です。申請方法は予約確定後にご案内します。`


**custom.lede**
```

```

**custom.features（feature_item ×4）**
1. title: `バナヒルズ「黄金の橋」` / description: `世界的に話題の絶景スポットで、非日常感のある一枚を残せます。`
2. title: `ミーケービーチ` / description: `世界が認める美しいビーチで、開放感あふれる撮影が叶います。`
3. title: `五つ星リゾートを貸切` / description: `ラグジュアリーリゾートの一角を使った、贅沢なロケーション撮影。`
4. title: `コストパフォーマンス` / description: `質の高い撮影・宿泊を、比較的抑えた費用で実現できます。`

**custom.seasons（season_card ×4）**
1. title: `2〜4月` / description: `気温・湿度ともに穏やかで、最も撮影しやすい時期。`
2. title: `5〜8月` / description: `晴天率が高い夏季。日差し対策をしつつ青空を狙えます。`
3. title: `9〜11月` / description: `雨季の始まり。屋内ロケーションを組み合わせるのがおすすめ。`

**custom.faqs（faq_item ×3）**

2. Q: `バナヒルズへの入場は撮影費用に含まれますか？`
   A: `ラグジュアリープランには入場料・ケーブルカー代が含まれます。ビーチプランでは含まれないため、詳細は商品ページの「含まれるもの」をご確認ください。`
3. Q: `雨季の撮影は避けるべきですか？`
   A: `9〜1月は降雨が多いため、屋内ロケーションを中心とした撮影プランをご提案しています。ベストシーズンの2〜8月をおすすめしています。`
