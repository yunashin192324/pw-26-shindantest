# ダナン ビーチプラン — Shopify フリーページ

`wedding-ec/products/danang-basic.html`（ダナン ビーチプラン）のレイアウト・UIを、
Shopify のテーマエディタで**項目ごとに編集・並び替え・表示/非表示できる**ように
セクション／ブロック構成へ書き換えたものです。

## 構成

もとの1枚のHTMLを、テーマエディタで個別に追加・削除・並び替えできる
13個の独立したセクションに分割しています。繰り返し項目（オプション・ギャラリー・
スケジュール・FAQなど）はセクション内の「ブロック」として、何個でも追加・削除・
並び替えができます。

| セクションファイル | 内容 |
| --- | --- |
| `sections/danang-header.liquid` | ヘッダー（ロゴ・ナビ・ボタン、ナビ項目はブロック） |
| `sections/danang-hero.liquid` | メインビジュアル（背景画像＋タイトル） |
| `sections/danang-breadcrumb.liquid` | パンくずリスト（項目はブロック） |
| `sections/danang-overview.liquid` | プラン概要＋料金パネル（説明文/タグ/料金パネルはブロック） |
| `sections/danang-included-excluded.liquid` | 含まれるもの／含まれないもの（各項目はブロック） |
| `sections/danang-options.liquid` | オプション一覧（各項目はブロック） |
| `sections/danang-dress.liquid` | ドレス紹介（画像＋文章） |
| `sections/danang-gallery.liquid` | ギャラリー（画像はブロック） |
| `sections/danang-schedule.liquid` | 当日スケジュール（各行はブロック） |
| `sections/danang-faq.liquid` | よくある質問（アコーディオン、各項目はブロック） |
| `sections/danang-reservation.liquid` | ご予約CTA |
| `sections/danang-footer.liquid` | フッター（リンク列はブロック） |
| `sections/danang-sticky-cta.liquid` | モバイル追従CTA |

共通のCSS（フォント読み込み・ボタン/カード/タグ/区切り線のスタイル）は
`snippets/danang-common.liquid` にまとめ、各セクションから読み込んでいます。
1セクションだけ削除しても他のセクションの見た目は崩れません。

`templates/page.danang-beach-plan.json` は、上記13セクションを元のページと
同じ内容・同じ並び順で登録済みのページテンプレートです。

## 使い方（インストール）

1. `sections/`・`snippets/`・`templates/` の中身を、Shopifyテーマの同名フォルダに
   そのままコピーします（Shopify CLIの `theme push`、またはテーマエディタの
   「コードを編集」からアップロード）。
2. Shopify管理画面の「オンラインストア > ページ」で新規ページを作成し、
   テンプレートに `page.danang-beach-plan`（表示名「Danang beach plan」）を選択します。
3. テーマエディタでそのページを開くと、13個のセクションが編集可能な状態で
   並んでいます。

## 各要望への対応

- **項目ごとにブロックにして編集できるように**
  → 各コンテンツはセクション（大項目）またはブロック（繰り返し項目）として分割。
    テーマエディタの「セクションを追加」「ブロックを追加」からいつでも増減・並び替え可能。
- **表示/非表示を選択できるように**
  → 各セクションに「このセクションを表示する」チェックボックスを追加（明示的なトグル）。
    加えて、Shopifyの仕様により各ブロックにも標準で「非表示にする」メニューが付きます。
- **フォントの大きさや色を選択できるように**
  → タイトル・本文などにカラーピッカーと文字サイズ（px指定のスライダー）を設定。
- **改行も自由にできるように**
  → タイトルや本文は複数行入力欄（テキストエリア）にしており、入力した通りに改行されます。
- **画像のトリミング**
  → 画像はShopify標準の「画像を選択」→ 編集画面のフォーカルポイント（トリミング位置）機能で
    調整できます（`object-fit: cover` ＋ `object-position` にフォーカルポイントを反映）。
- **画像に文字を載せても見えづらくならないように**
  → メインビジュアル（ヒーロー画像）にオーバーレイの色・濃さ（%）を設定できるようにし、
    背景画像の明るさに応じて文字の視認性を調整できます。

## 制限事項

- フッターの各リンク列は、実装をシンプルにするため「1行1項目のテキスト」としており、
  個別リンク（URL）は付いていません。リンク付きにしたい場合はご要望ください
  （各行をブロック化して個別にURLを持たせる形に変更できます）。
- ヘッダー／フッターは他のページと共通化したい場合、通常はテーマの `sections/header.liquid`
  `sections/footer.liquid`（テーマ全体で共通のグローバルセクション）に寄せる方法もあります。
  今回は既存テーマ構成が無い前提で、フリーページ単体で完結するように作成しています。
