# 世界のプロポーズプラン — モックアップ（v2）

**`all-in-one.html` をダブルクリックするだけで見られます。** CSS・JS・写真をすべて1ファイルに
埋め込んでいるので、オフラインのPCでもそのまま動きます（外部通信は Google Fonts のみ。
つながらない場合は端末の標準フォントで表示されます）。スマホでも同じファイルが見られます。

## 見られる画面

| 画面 | 開き方 |
|---|---|
| TOP | ファイルを開いた最初の画面 |
| ロケーション詳細 | TOPの写真カードをタップ（例: パリ） |
| 予約フロー | 詳細ページの「空き状況」で時間を選ぶ →「この日時で予約する」 |

ブラウザの「戻る」でひとつ前の画面に戻れます。

## ファイル構成

```
propose-lp/
├── all-in-one.html   ← 配布用（ビルド結果。直接編集しない）
├── build.py          ← src/ と images/ から all-in-one.html を作る
├── src/
│   ├── template.html   画面の骨組み（ヘッダー・TOP・予約フローの枠）
│   ├── styles.css      デザイン
│   ├── data.js         旅行先・料金・オプション・空き状況ルール（Shopifyのメタオブジェクトと同じ項目）
│   └── app.js          画面切り替え・ロケーション詳細・空き状況・予約フロー
└── images/<旅行先ID>.jpg  旅行先の写真（ない旅行先はイラストで代替表示）
```

変更したら `python3 propose-lp/build.py` で `all-in-one.html` を作り直します
（`--dev` を付けると写真を埋め込まない軽い `dev.html` を作ります。`python3 -m http.server` で確認用）。

## デモ用の仮データ

- 所要時間・受付締切（最短○日前）・雨天対応・空き状況は仮データです。画面にもその旨を表示しています。
  空き状況は日付と時間から決まる擬似的な値で、実際の在庫ではありません。
- 「お支払いへ進む」を押しても決済は行われません（実サイトでは Shopify の決済画面へ移動します）。
- 実績の数字やお客様の声は載せていません。

Shopifyへの実装方法・データ設計は `/shopify-theme/PROPOSE-README.md` を参照してください。
