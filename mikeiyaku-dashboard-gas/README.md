# 46期未成約リスト ダッシュボード（GAS + Web App SPA）

「46期未成約リスト」Googleスプレッドシートの構造を再現した、GAS（Google Apps Script）製のデータ管理・分析Webアプリです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `InitSheet.gs` | データベース（スプレッドシート）の初期化スクリプト。10店舗分のデータシート・店舗別サマリ・個人別サマリ(上期/下期)を1クリックで自動構築します。 |
| `Code.gs` | バックエンドAPI。`doGet`・マスタ取得・全データ取得・個人別サマリ取得・新規登録・インライン更新を提供します。 |
| `Index.html` | SPAのUI本体（Tailwind CSS / FontAwesome / Chart.js を使用）。 |
| `Javascript.html` | クライアントサイド制御ロジック（`Index.html` に `<?!= include('Javascript'); ?>` でインクルードされます）。 |
| `appsscript.json` | GASプロジェクトのマニフェスト（Webアプリとして公開する設定）。 |

## セットアップ手順

1. 対象のGoogleスプレッドシートを開き、「拡張機能」→「Apps Script」でスクリプトエディタを開く。
2. `Code.gs`・`InitSheet.gs`・`Index.html`・`Javascript.html`・`appsscript.json`（マニフェストの表示をオンにして反映）を、それぞれ同名のファイルとしてすべて貼り付ける。
3. スプレッドシートを再読み込みすると、メニューに「46期未成約ダッシュボード」が追加されるので、「① 全シートを初期化（InitSheet）」を実行する（初回のみ。既存シートは上書きされません）。
4. スクリプトエディタから「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選択し、アクセスできるユーザーを設定してデプロイする。
5. 発行されたURLにアクセスすると、ダッシュボードが表示されます。

## 主な機能

- **店舗分析ダッシュボード**: 店舗・月フィルタ、月次推移グラフ（未成約件数×成約件数の混合チャート）、未成約理由割合ドーナツチャート、ソート可能な店舗別ランキング。
- **個人別サマリー**: 上期/下期切り替え、社員別月次マトリクス表示、リアルタイム検索。
- **未成約相談データ管理**: 複合フィルタ、ページネーション付きデータグリッド、STS/成約PAX/詳細等のインライン即時編集（保存は `updateStatus` / `updateCellValue` API経由）、新規相談登録モーダル。

すべてのデータ取得はページ初期表示時にまとめて非同期取得し、ブラウザ側のキャッシュ（`allDataCache`）に対してフィルタ処理を行うことで、サーバー再問い合わせなしの高速な絞り込みを実現しています。
