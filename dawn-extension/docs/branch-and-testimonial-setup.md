# 「支店」「体験談」Metaobject・メタフィールドの追加手順

2026-07-25に追加した2機能のための設定手順です。コードは反映済みですが、
以下のMetaobject定義・メタフィールドはまだ存在しないため、この手順どおりに
作成しないと該当セクションは何も表示されません（未作成の間はエラーにはならず、
単に非表示になります）。

---

## 1. 「支店」Metaobject（現地拠点のご紹介・プラン商品ページ用）

設定 →「メタオブジェクト」→「定義を追加」

- **名前**：支店（タイプ：`branch`）
- フィールド：

| フィールド名 | キー (Key) | タイプ | 必須 | 備考 |
|---|---|---|---|---|
| 支店名 | `name` | 単一行テキスト | ○ | 例：ローマ支店 |
| 国・地域 | `location` | 単一行テキスト | 任意 | 例：イタリア・ローマ |
| 紹介文 | `description` | 複数行テキスト | 任意 | |
| 画像 | `image` | ファイル（画像） | 任意 | **「リストにする」はチェックしない**（1支店1枚）。空欄でもレイアウトは崩れません。トリミング位置を変えたい場合は、画像のALTテキストに`説明文｜位置`と書いてください（例：`ローマ支店外観｜下`。位置の書き方は既存のフォトギャラリーと同じ：上/下/左/右/中央/左上/右上/左下/右下） |

### プラン商品への紐付け

コンテンツ →「支店」でローマ支店などを1件作成したら、次に商品側に
「担当支店」欄を追加します。

設定 →「メタフィールド」→「商品」→「定義を追加」

- **名前**：担当支店（キー：`branch`、名前空間：`custom`）
- タイプ：**メタオブジェクトの参照**（単数・リストにしない）、参照先「支店」

この欄を設定した商品（プラン）のページにだけ「現地拠点のご紹介」ブロックが
自動で表示されます。**設定しない商品（提携パートナー手配のプラン等）には
何も表示されません。** 同じ支店を複数の商品で使い回せるので、支店情報の
入力は支店ごとに1回だけで済みます。

## 2. 「体験談」Metaobject（先輩カップルの声）

設定 →「メタオブジェクト」→「定義を追加」

- **名前**：体験談（**タイプは`story`にしてください**。「名前」欄と
  「タイプ」欄は別物で、タイプ欄は自動生成された値がそのまま残ることが
  あります。作成直後の編集画面で「タイプ：〇〇」という表示を必ず確認し、
  `story`になっていない場合は編集して`story`に合わせてください。
  destination-testimonials.liquid / testimonials-top.liquidのコードが
  `shop.metaobjects.story.values`という名前でこのメタオブジェクトを
  探しに行くため、タイプが一致していないと体験談が一切表示されません）
- フィールド：

| フィールド名 | キー (Key) | タイプ | 必須 | 備考 |
|---|---|---|---|---|
| お呼び名 | `name` | 単一行テキスト | ○ | 例：K & Yさま |
| 撮影地 | `destination` | メタオブジェクトの参照（単数）、参照先「Destination」 | ○ | この体験談がどの都市のものかを1件選ぶ |
| ご利用時期 | `usage_date` | 単一行テキスト | 任意 | 例：2026年5月 |
| お写真 | `photos` | ファイル（画像）の**リスト** | 任意 | 複数枚まとめて選択・アップロードできます。0枚でも画像枠は自動的に非表示になります。2枚以上あると矢印/スワイプで送れるスライダーになります。各画像のALTテキストに`説明文｜位置`と書くとその1枚だけトリミング位置を変えられます（フォトギャラリーと同じ規約） |
| Q&A | `qa_pairs` | 複数行テキスト | 任意 | **1行に1組、`質問｜回答`の形式**で書いてください。何行でも追加できます（＝質問の数に制限はありません）。例：<br>`挙式の決め手は？｜写真の綺麗さです`<br>`現地の言葉は不安でしたか？｜スタッフの方がずっと日本語対応してくれて安心でした` |
| TOPページに掲載 | `featured` | 真偽値（チェックボックス） | 任意 | チェックを入れた体験談だけ、TOPページの「先輩カップルの声」入口に抜粋表示されます |

### 都市ごとに体験談を作る

1. コンテンツ →メタオブジェクト →「体験談」→「エントリーを追加」
2. `name`（お呼び名）、`destination`（対象都市を1つ選択）を入力
3. 必要に応じて`usage_date`・`photos`・`qa_pairs`を入力
4. TOPページにも載せたい場合だけ`featured`にチェック
5. 保存

同じ都市の体験談をもう1件作りたい場合は、同じ手順を繰り返してください
（Reason/FAQ Itemと同じ「エントリーを追加するたびに対象都市を選ぶ」方式です）。

### 表示される場所

- **各都市ページ**：`destination-testimonials`セクションが、その都市の
  `destination`を指す体験談だけを自動的に集めて表示します（1件も無ければ
  セクションごと非表示）。テーマエディタで表示位置の変更や見出し文言の
  変更は可能ですが、セクション自体は`page.destination.json`に既に
  組み込み済みなので、貼り替え後は追加設定なしでそのまま動きます。
- **TOPページ**：`testimonials-top`セクションが、`featured`にチェックが
  入った体験談だけを抜粋してカード一覧表示します。このセクションは
  TOPページのテンプレートにまだ組み込まれていないため、テーマエディタで
  TOPページを開き、「セクションを追加」→「体験者の声(TOP)」から追加して
  ください。カードをクリックすると、その都市ページの体験談セクションへ
  ジャンプします。
