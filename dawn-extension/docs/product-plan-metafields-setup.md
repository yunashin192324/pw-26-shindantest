# プラン商品のメタフィールド — テンプレート共有セットアップ

プランが増えるたびに`location-plan`テンプレートを複製すると管理が
大変になるため、プランごとの内容を**商品のメタフィールド**に入れる
ことで、**1つのテンプレートを全プラン商品で共有**できるようにしました。

メタフィールドを設定しなければ、今まで通りテンプレートを複製して
セクション設定・ブロックで作る方法も引き続き使えます（既存のダナン・
ロンドンのページはそのまま壊れません）。**メタフィールドが設定されて
いれば、そちらが優先して使われます。**

## 1. メタフィールド定義の作成

管理画面 →「設定」→「メタフィールド」→「商品」を開き、「定義を追加」で
以下を**すべて`custom`という名前空間**（デフォルトのまま）で作成して
ください。

「リスト」型はShopify管理画面での設定が分かりづらく、また保存時に
"選択リスト"という別のタイプと混同しやすいため、**リスト型は一切
使わず、すべて単一の値のタイプ**（単一行/複数行テキスト・JSON）だけで
完結する構成にしています。「タイプ」を選ぶ時に出てくる「1つ／リスト」
のトグルには触らないでください。

| # | 名前 | キー | タイプ | 備考 |
|---|---|---|---|---|
| 1 | プラン ヒーロー英字見出し | `plan_hero_eyebrow` | 単一行テキスト | 例: `DA NANG — PHOTO WEDDING` |
| 2 | プラン ヒーローリード文 | `plan_hero_lede` | 複数行テキスト | |
| 3 | プラン ヒーロー文字色 | `plan_hero_text_color` | 単一行テキスト | `#ffffff`のように入力。画像が明るい場合は`#1a1a1a`等に |
| 4 | プラン概要見出し | `plan_overview_title` | 単一行テキスト | 例: `世界的に評価されるビーチで撮る一枚` |
| 5 | 価格の注記 | `plan_price_note` | 単一行テキスト | 例: `税込 / 2名様` |
| 6 | キャンセル規定 | `plan_price_cancel_note` | 複数行テキスト | |
| 7 | 含まれるもの | `plan_included_items` | **複数行テキスト** | 1行に1項目ずつ改行して入力（リスト化不要） |
| 8 | 含まれないもの | `plan_excluded_items` | **複数行テキスト** | 同上 |
| 9 | オプション | `plan_options` | **複数行テキスト** | 1行1項目、`名称｜価格`の形式。例: `送迎付きプラン｜+¥12,000` |
| 10 | スケジュール | `plan_schedule` | **複数行テキスト** | 1行1項目、`時刻｜内容`の形式。例: `8:00｜サロンにてお仕度開始` |
| 11 | FAQ | `plan_faqs` | **複数行テキスト** | 1行1項目、`質問｜回答`の形式。例: `ビザは必要ですか？｜不要です` |
| 12 | 注意事項 | `plan_notes` | 複数行テキスト | |
| 13 | 撮影地名（戻りリンク用） | `plan_area_name` | 単一行テキスト | 例: `ダナン`。設定するとパンくずに表示 |
| 14 | 撮影地ページURL（戻りリンク用） | `plan_area_url` | 単一行テキスト | 例: `/pages/danang-photo-wedding`。このプランが属する都市詳細ページのURL |

**オプション・スケジュール・FAQの入力ルールはすべて共通です：1行に1項目、
2つの情報は｜（縦棒）で区切ります。** JSONの知識は一切不要です。

```
送迎付きプラン｜+¥12,000
アルバム追加｜+¥8,000
```

上記のように、2行目・3行目…と項目を増やしたい場合は改行して同じ形で
書き足すだけです。｜（縦棒）はキーボードの `Shift + ¥`（またはIMEで
「たてぼう」と入力）で出せます。全角の｜でも半角の\|でもどちらでも
正しく認識されます。

⚠️ すでに`plan_options`・`plan_schedule`・`plan_faqs`をJSON型で作成
済みの場合は、**メタフィールドの「タイプ」は後から変更できません**。
一度削除して「複数行テキスト」タイプで作り直し、上記の形式で入力し
直してください（幸い今のところ入力済みのプランは少ないため、移行の
手間は小さいはずです）。

**特徴タグ（「ダブルカメラマン」等のピル表示）はメタフィールド不要です。**
商品の**タグ**欄にそのまま入力すれば自動でピル表示されます
（`即予約`・`人気`タグは表示制御用なので、ピルには出ません）。

**ギャラリー画像もメタフィールド不要です。** 商品の**「メディア」欄**
（標準機能、複数枚まとめてアップロード可）に画像を登録してください。
**1枚目はヒーロー画像として使われ、2枚目以降が自動的にギャラリーとして
表示されます。**

## 2. テンプレートを1つだけ用意する

1. すでにある`location-plan`テンプレートをそのまま使う（複製しない）
2. 新しいプラン商品を作るときは、**同じ`location-plan`テンプレート**を
   選択する

## 3. 新しいプランを追加する手順（複製なし）

1. 商品管理 →「商品を追加」
2. タイトル・価格・画像・タグ（`即予約`等）を入力
3. テーマテンプレートで`location-plan`を選択
4. 商品の編集画面を下にスクロールすると「メタフィールド」欄が出てくる
   ので、上表の項目を入力
5. 保存

これだけで、テンプレートを複製せずに新しいプランページが追加できます。

## 4. 既存メタフィールドを流用している項目

以下の3つは新規作成ではなく、**もともと店舗に存在していた既存の
メタフィールドをそのまま流用**して「ご予約にあたって」欄に表示しています。
新しく設定を作る必要はありません。すでに値が入っている商品はそのまま
表示されます。

| 名前 | キー | タイプ |
|---|---|---|
| 運行事業者 | `custom.agt` | 単一行テキスト |
| お申し込み時に必要なもの | `custom.need` | リッチテキスト |
| 撮影不可能日 | `custom.ngday` | リッチテキスト |

3つとも空欄の商品では「ご予約にあたって」セクション自体が非表示になります。

## 5. 既存のダナン・ロンドンページはどうする？

そのままで問題ありません。メタフィールドが未設定の商品は、今まで通り
テンプレート内のセクション設定・ブロックの内容が使われます。時間の
あるときに、ダナン・ロンドンの内容もメタフィールドに移せば、複製した
テンプレートを削除して`location-plan`1つに統合できます（急ぎではあり
ません）。
