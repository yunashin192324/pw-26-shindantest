# Destination Metaobjectへのフィールド追加

既存の`Destination`Metaobject定義（設定 → メタオブジェクト → Destination）に、
以下の3フィールドを追加してください。追加するだけで、既存の都市データは
一切壊れません（未入力の間は該当セクションが自動的に非表示になります）。

| # | フィールド名 | キー (Key) | タイプ | 備考 |
|---|---|---|---|---|
| 19 | 選ばれる理由 | `reasons` | JSON（リスト） | `[{"title":"見出し","description":"本文"}]` 形式 |
| 20 | モデルスケジュール | `schedule` | JSON（リスト） | `[{"time":"1日目","description":"内容"}]` 形式 |
| 21 | フォトギャラリー画像 | `gallery_images` | ファイル（画像）の**リスト** | 通常のファイル欄と違い、複数枚まとめて選択・アップロードできます |
| 22 | 撮影スポット | `photo_spots` | Metaobjectのリスト（参照先：「Photo Spot」※後述） | JSON手入力ではなく、新規作成ボタンからその場で1件ずつ追加し、画像もその場でアップロードできる方式 |
| 23 | よくある質問 | `faqs` | JSON（リスト） | `[{"question":"質問文","answer":"回答文"}]` 形式 |
| 24 | カード画像トリミング位置 | `hero_image_position` | 単一行テキスト | 都市一覧などの縦長カードで`hero_image`をどの位置基準で切り抜くか。`top`／`center`／`bottom`／`30% 50%`のような値。未入力なら`center`扱い |

## 手順

1. 管理画面 →「設定」→「メタオブジェクト」→「Destination」を開く
2. 「フィールドを追加」を上表の通り作成する
   - `reasons`・`schedule`：タイプは「JSON」を選択
   - `gallery_images`：タイプは「ファイル」を選択したあと、「**リストにする**」のチェックを入れる（これで1つの欄に複数画像をまとめて登録できます）
   - `photo_spots`：下記「撮影スポットを画像アップロード対応にする」の手順で作成
3. 保存

## 撮影スポットを画像アップロード対応にする（`photo_spots`の作り方）

JSONを手で書く代わりに、「Photo Spot」という小さなメタオブジェクトを1つ用意し、
Destinationの`photo_spots`欄をそこへの参照リストにします。これで、都市エントリーの
編集画面のまま「新規作成」→画像をその場でアップロード、という流れで撮影スポットを
追加できます。

### ① 「Photo Spot」メタオブジェクト定義を新規作成する

1. 管理画面 →「設定」→「メタオブジェクト」→「定義を追加」
2. 名前：「Photo Spot」
3. フィールドを3つ追加
   - `title`：単一行テキスト
   - `description`：複数行テキスト
   - `image`：ファイル（画像）※「リストにする」はチェックしない（1スポット1枚）
4. 保存

### ② Destinationの`photo_spots`フィールドを作る

1. 「設定」→「メタオブジェクト」→「Destination」→「フィールドを追加」
2. タイプで「**Metaobjectのリスト**」（または「参照」の中の該当項目）を選択
3. 参照先メタオブジェクトとして①で作った「Photo Spot」を選択
4. キーは`photo_spots`
5. 保存

### ③ 都市エントリーで使う

1. 都市（例：ハワイ）のメタオブジェクトエントリーを開く
2. `photo_spots`欄の「追加」→「新規作成」
3. その場で開くフォームに`title`（スポット名）・`description`（説明文）を入力し、
   `image`欄の「画像をアップロード」ボタンで直接アップロード
4. 保存すると1件のスポットが追加される。同じ手順を繰り返して2件目、3件目を追加
5. 都市エントリー全体を保存

## 入力例（既存の都市に追記する場合）

コンテンツ → メタオブジェクト → Destination → 対象都市のエントリーを開き、

- `reasons`欄に以下のようなJSONを貼り付け:
  ```json
  [
    { "title": "【ノンストレス】", "description": "日本から直行便で約5時間半の好アクセス。時差もたった2時間なので、体への負担が少なく短いお休みでもスケジュールが組みやすいのが魅力です。" },
    { "title": "【海×世界遺産】", "description": "透明度の高いビーチと、車で約30分の世界遺産の街を1日で贅沢に楽しめます。" }
  ]
  ```
- `schedule`欄に以下のようなJSONを貼り付け:
  ```json
  [
    { "time": "1日目", "description": "成田空港発ーダナン着" },
    { "time": "2日目", "description": "撮影日" }
  ]
  ```
- `gallery_images`欄には、画像を複数選択してまとめてアップロード

JSONの書き方に不安があれば、既存のarea-2ページの内容を貼り付けるので、その都度私が変換します。
