# Destination Metaobjectへのフィールド追加

既存の`Destination`Metaobject定義（設定 → メタオブジェクト → Destination）に、
以下の3フィールドを追加してください。追加するだけで、既存の都市データは
一切壊れません（未入力の間は該当セクションが自動的に非表示になります）。

| # | フィールド名 | キー (Key) | タイプ | 備考 |
|---|---|---|---|---|
| 19 | 選ばれる理由 | `reasons` | JSON（リスト） | `[{"title":"見出し","description":"本文"}]` 形式 |
| 20 | モデルスケジュール | `schedule` | JSON（リスト） | `[{"time":"1日目","description":"内容"}]` 形式 |
| 21 | フォトギャラリー画像 | `gallery_images` | ファイル（画像）の**リスト** | 通常のファイル欄と違い、複数枚まとめて選択・アップロードできます |
| 22 | 撮影スポット | `photo_spots` | JSON（リスト） | `[{"title":"見出し","description":"本文","image":"https://..."}]` 形式。`image`は該当スポットの画像URL（Shopifyのファイル一覧にアップロードした画像のURLをコピーして入力） |
| 23 | よくある質問 | `faqs` | JSON（リスト） | `[{"question":"質問文","answer":"回答文"}]` 形式 |

## 手順

1. 管理画面 →「設定」→「メタオブジェクト」→「Destination」を開く
2. 「フィールドを追加」を3回、上表の通り作成する
   - `reasons`・`schedule`：タイプは「JSON」を選択
   - `gallery_images`：タイプは「ファイル」を選択したあと、「**リストにする**」のチェックを入れる（これで1つの欄に複数画像をまとめて登録できます）
3. 保存

## 入力例（既存の都市に追記する場合）

コンテンツ → メタオブジェクト → Destination → 対象都市のエントリーを開き、

- `reasons`欄に以下のようなJSONを貼り付け:
  ```json
  [
    { "title": "【ノンストレス】", "description": "日本から直行便で約5時間半の好アクセス。時差もたった2時間なので、体への負担が少なく短いお休みでもスケジュールが組みやすいのが魅力です。" },
    { "title": "【海×世界遺産】", "description": "透明度の高いビーチと、車で約30分の世界遺産の街を1日で贅沢に楽しめます。" }
  ]
  ```
- `schedule`欄に以下のようなJSONを貼り付け:
  ```json
  [
    { "time": "1日目", "description": "成田空港発ーダナン着" },
    { "time": "2日目", "description": "撮影日" }
  ]
  ```
- `gallery_images`欄には、画像を複数選択してまとめてアップロード

JSONの書き方に不安があれば、既存のarea-2ページの内容を貼り付けるので、その都度私が変換します。
