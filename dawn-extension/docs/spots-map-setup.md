# 撮影スポットMAPの設定手順

2026-07-25に追加した機能です。Leaflet + OpenStreetMap（完全無料、
Googleのようなアカウント登録・請求先設定・APIキー発行は一切不要）を
使っています。

**1点だけ注意**：これまでのTailwind/Lucideは容量の小さいファイルを
このリポジトリに直接コピーして自己ホスト化していましたが、Leafletは
現在の作業環境からダウンロードできなかったため、外部CDN
（jsDelivr）から直接読み込む形にしています。動作上の問題はありませんが、
「外部サービスに一切依存しない」という以前の方針からは少し外れます。
気になる場合は、`https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js`
と`leaflet.css`をダウンロードしてアップロードしていただければ、
他のライブラリと同じように自己ホスト化するコードに直せます。

---

## 1. 「Spot Category」Metaobject（カテゴリの選択肢）

設定 →「メタオブジェクト」→「定義を追加」

- **名前**：Spot Category（タイプ：`spot_category`）
- フィールド：`label`（単一行テキスト）

作成後、コンテンツ →メタオブジェクト →「Spot Category」で、以下の
6エントリーを作成してください（画像位置のメタオブジェクトと同じ、
クリックで選ぶための固定選択肢です）。`label`欄にそのまま入力するだけです。

- 教会
- 海
- ホテル
- 自然
- 街並み
- その他

**カテゴリを増やしたい場合**：ここにエントリーを追加すれば選べるように
なりますが、地図上のピンの色は`spots-map.liquid`内で6色だけ固定で
割り当てています。新しいカテゴリは自動的にグレー（その他と同じ色）に
なります。特定の色を割り当てたい場合はお知らせください。

## 2. 「Photo Spot」Metaobjectにフィールドを追加

既存の「Photo Spot」定義に、以下を追加してください。

| フィールド名 | キー (Key) | タイプ | 備考 |
|---|---|---|---|
| 緯度 | `latitude` | 数値（小数） | 例：35.6895 |
| 経度 | `longitude` | 数値（小数） | 例：139.6917 |
| カテゴリ | `category` | メタオブジェクトの参照（単数）、参照先「Spot Category」 | クリックで選択 |

緯度・経度の調べ方：Googleマップで場所を右クリック →表示された座標
（例：`35.6895, 139.6917`）をコピーし、前半を緯度、後半を経度に
それぞれ入力してください。

**この2つが未入力のスポットは地図に出ません**（エラーにはならず、
単に表示されないだけです）。入力したスポットから順に地図に反映されます。

## 3. ページを作成する

1. オンラインストア →ページ →「ページを追加」
2. タイトルに「撮影スポットMAP」などと入力
3. 右側の「テーマテンプレート」を`page.spots-map`に設定
4. 保存
5. オンラインストア →テーマ →カスタマイズで、このページを開き、
   `/pages/destinations`と同じ「レイアウト」（独自ヘッダー/フッターの方）
   が選ばれているか確認（前回の「撮影地 人気ランキング」ページ作成時と
   同じ手順です）

地図に表示される内容（見出し・説明文）はテーマエディタのセクション
設定から変更できます。カテゴリの絞り込みチップは、実際にデータが
入っているカテゴリだけが自動的に出てきます。
