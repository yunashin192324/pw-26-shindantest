# ダナンページを新しい共通テンプレートに移行する手順

現在ダナンは`area-2`という個別ページ（`area-lp.liquid`セクション）で運用されています。
これを、都市が増えても壊れない共通テンプレート（`page.destination.json` /
`destination-*.liquid`）に移行する手順です。**いきなり本番を切り替えず、
テスト用の別ページで確認してから最後に切り替える**流れにしています。

## 事前準備：Metaobjectのフィールド追加

`docs/destinations-metaobject-fields-addition.md`の手順で
`reasons`／`schedule`／`gallery_images`の3フィールドを追加しておいてください。

## ステップ1：URL（ページhandle）をどうするか決める

2つの選択肢があります。

- **A. `area-2`のままにする**（おすすめ・作業が楽）：MetaobjectのDestinationエントリーの
  `slug`欄に`area-2`と入力する。既存のURL・被リンク・SEO評価がそのまま維持される
- **B. `danang`のような分かりやすいURLに変える**：`slug`を`danang`にして、ページのhandleも
  `danang`に変更 → 旧URL `area-2` から新URL `danang` への**リダイレクト設定**が別途必要
  （管理画面 →「オンラインストア」→「ナビゲーション」→「URLリダイレクト」）

とくにこだわりがなければ**A**を推奨します。

## ステップ2：Danang用のMetaobjectエントリーを作る

1. 管理画面 → コンテンツ → メタオブジェクト → Destination →「エントリーを追加」
2. 基本情報を入力：
   - `name_ja`: ダナン
   - `name_en`: Da Nang
   - `slug`: `area-2`（ステップ1でAを選んだ場合）
   - `hero_image`: 現在のヒーロー画像をアップロード
   - `region`: `asia`
   - `country`: ベトナム
   - `description`: 現在のリード文
3. `reasons`・`schedule`・`photo_spots`・`faqs`の各JSON欄は、**今のarea-2ページの内容を
   全部そのまま私に貼ってもらえれば**、正しいJSON形式に変換してお渡しします
   （今回のやり取りで見えた範囲のデータだけでは、選ばれる理由・撮影スポット・
   スケジュール・FAQが全項目そろっているか確証が持てないため、変換前に
   現状の全ブロックの内容を確認させてください）
4. `gallery_images`：現在ギャラリーに使っている画像をまとめてアップロード

## ステップ3：プラン（商品）をコレクションに紐付ける

新しいテンプレートの「プラン一覧」は、**`area-2`という handle のコレクション**に
入っている商品を自動表示する仕組みです（個別ブロックでの手動リンク作業が不要になります）。

1. 商品管理 →「コレクション」→「コレクションを作成」
2. タイトルは何でもよいですが、**URLのhandleを`area-2`に**する（自動生成されるURLを編集）
3. 「商品」欄で、ダナンのプラン商品（例：ダナンビーチフォトプラン）を追加
4. 保存

## ステップ4：テスト用ページで確認する

1. 管理画面 →「オンラインストア」→「ページ」→「ページを追加」
2. タイトル：「ダナン（テスト）」など分かりやすい名前 → 一旦適当なURLでOK
3. 「テーマテンプレート」欄で`destination`を選択
4. 保存し、プレビューで表示を確認（ヒーロー・理由・撮影スポット・スケジュール・
   ギャラリー・プラン・FAQが正しく出るか）
5. 問題なければステップ5へ、崩れていればスクリーンショットを送ってください

## ステップ5：本番切り替え

1. 既存の`area-2`ページの編集画面を開く
2. 「テーマテンプレート」欄を`area-lp`（今のもの）から`destination`に変更
3. 保存
4. テスト用に作った仮ページ（ステップ4）は削除してOK

## 補足

- 旧`area-lp.liquid`・`page.area-2.json`のコードは、切り替え後すぐに消さずしばらく
  残しておいて大丈夫です（テンプレートを切り替えるだけで使われなくなるだけなので、
  何かあってもテーマテンプレートを元の`area-lp`に戻せば即座に復元できます）
- この移行が済めば、次の都市からは「Metaobjectにエントリー1件追加」＋
  「コレクションに商品を入れる」だけで新しい撮影地ページが増やせます。
  テンプレートの複製作業は不要になります
