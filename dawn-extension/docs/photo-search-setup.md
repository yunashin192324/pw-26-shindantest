# 「写真から探す」の設定手順

新しいメタオブジェクトやメタフィールドは不要です。既存の都市フォトギャラリー
（各都市のDestinationメタオブジェクトの`gallery_images`欄）の画像ALTテキスト
規約を拡張しただけです。

## ALTテキストの書き方（拡張版）

これまで：`説明文｜位置`
今後：**`説明文｜位置｜タグ1,タグ2`**（3つ目にタグをカンマ区切りで追加）

例：
```
チャペル外観｜下｜教会,街並み
ワイキキビーチの夕暮れ｜下｜海,夕景
```

- 3つ目（タグ）を省略しても今まで通り動きます（後方互換あり、既存の画像を
  書き直す必要はありません）。
- タグは自由に決めてOKです。実際に入力されたタグが、絞り込みチップとして
  自動的に画面に出てきます（あらかじめ決まった一覧を用意する必要はありません）。
- 位置（トリミング）を指定しないがタグだけ付けたい場合は、真ん中を空欄に
  してください：`チャペル外観｜｜教会`

## ページを作成する

1. オンラインストア →ページ →「ページを追加」
2. タイトルに「写真から探す」などと入力
3. 右側の「テーマテンプレート」を`page.photo-search`に設定
4. 保存
5. オンラインストア →テーマ →カスタマイズでこのページを開き、
   `/pages/destinations`と同じ「レイアウト」（独自ヘッダー/フッターの方）
   が選ばれているか確認（ランキングページ・MAPページと同じ手順）

見出し・説明文はテーマエディタのセクション設定から変更できます。
