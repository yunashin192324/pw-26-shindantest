# 撮影地一覧 — Metaobject「destination」セットアップ手順

100以上の撮影地に拡張していく想定のため、撮影地1件＝Page 1枚を都度
手作業で作る（今のダナンの`area-lp`のような作り方）のではなく、
**Metaobjectにデータを1件登録するだけで自動的にページが完成する**
仕組みにしています。

## STEP 1. Metaobject定義を作成（最初の1回だけ）

**設定 → メタオブジェクト → 定義を追加**。タイプ名は半角小文字で
`destination` としてください（コードが直接この名前を参照するため、
1文字でも違うと動きません）。

以下のフィールドを、上から順番に追加してください。

| # | 名前（表示用） | キー（半角） | フィールドの種類 | 必須 |
|---|---|---|---|---|
| 1 | 都市名（日本語） | `name_ja` | 単一行テキスト | ✅ |
| 2 | 英語名 | `name_en` | 単一行テキスト | ✅ |
| 3 | slug（URLハンドル） | `slug` | 単一行テキスト | ✅ |
| 4 | Hero画像 | `hero_image` | ファイル（画像） | ✅ |
| 5 | 地域 | `region` | 単一行テキスト | ✅ |
| 6 | 国 | `country` | 単一行テキスト | ✅ |
| 7 | 説明（撮影の魅力） | `description` | 複数行テキスト | ✅ |
| 8 | テーマ | `themes` | 単一行テキストのリスト | 任意 |
| 9 | 人気 | `popular` | 真偽値 | 任意 |
| 10 | 表示順 | `sort_order` | 整数 | 任意 |
| 11 | SEOタイトル | `seo_title` | 単一行テキスト | 任意 |
| 12 | SEO説明文 | `seo_description` | 複数行テキスト | 任意 |
| 13 | 飛行時間 | `flight_time` | 単一行テキスト | 任意 |
| 14 | 時差 | `time_difference` | 単一行テキスト | 任意 |
| 15 | ベストシーズン | `best_season` | 単一行テキスト | 任意 |
| 16 | おすすめな人 | `recommended_for` | 単一行テキスト | 任意 |
| 17 | 撮影スポット | `locations` | JSON | 任意 |
| 18 | モデルスケジュール | `schedule` | JSON | 任意 |
| 19 | よくある質問 | `faqs` | JSON | 任意 |
| 20 | ギャラリー画像 | `gallery` | ファイルのリスト（画像） | 任意 |
| 21 | **プラン（商品）** | `plans` | **商品参照のリスト** | 任意 |

> **21番が今回の肝です。** ここに、この撮影地のプラン商品
> （`dawn-extension/templates/product.json` で作ったProductなど）を
> 直接複数選択してください。価格・在庫・バッジ（即予約／リクエスト
> 予約・人気）は常に商品側の実データから自動反映されるので、ここに
> 価格などを手入力する必要は一切ありません。

保存すれば、これで「撮影地データの入力フォーム」が完成です。

## STEP 2. 地域キー一覧（「地域」欄に入力する値）

必ずこの8つのうちどれかを、このスペルのまま入力してください。

| 入力する値 | 意味 | 対応する地域ページURL |
|---|---|---|
| `europe` | ヨーロッパ | `/pages/europe` |
| `america` | アメリカ大陸 | `/pages/america` |
| `asia` | アジア | `/pages/asia` |
| `oceania` | オセアニア | `/pages/oceania` |
| `middle_east` | 中東 | `/pages/middle-east`（ハイフン区切り） |
| `africa` | アフリカ | `/pages/africa` |
| `south_america` | 南米 | `/pages/south-america`（ハイフン区切り） |
| `japan` | 日本 | `/pages/japan` |

## STEP 3. JSON項目の書き方（撮影スポット／スケジュール／FAQ）

空欄のままでも問題なく動きます（該当セクションが自動的に非表示に
なるだけです）。書く場合は、以下の形式でそのまま貼り付けてください。

**撮影スポット (`locations`)**
```json
[
  { "name": "ミーケビーチ", "description": "透明度の高い広大なビーチで開放感あふれる撮影" },
  { "name": "ホイアン", "description": "世界遺産のホイアンで、カラフルでノスタルジックな撮影" }
]
```

**モデルスケジュール (`schedule`)**
```json
[
  { "day": "1日目", "description": "成田空港発ーダナン着\nホテル泊" },
  { "day": "2日目", "description": "フォトウェディング撮影（ビーチフォトの場合）" }
]
```

**よくある質問 (`faqs`)**
```json
[
  { "question": "ビザは必要ですか？", "answer": "15日以内の観光滞在であればベトナム入国時のビザは原則不要です。" }
]
```

## STEP 4. 撮影地データを入力する（1件ごとに繰り返し）

1. **コンテンツ → メタオブジェクト → destination → エントリーを追加**
2. STEP1の項目を入力（ダナンの実例は下記参照）
3. **オンラインストア → ページ → ページを追加**
   - タイトル：撮影地名（例：ダナン）
   - URLハンドル：Metaobjectの`slug`と完全に一致させる（例：`danang`）
   - テーマテンプレート：`page.destination`
4. 保存すれば `https://ストアURL/pages/danang` で表示されます

**コードの修正は一切不要です。** 撮影地が2件目、3件目…と増えても、
同じ手順の繰り返しだけで対応できます。

### ダナンの入力例（既存area-lpの内容を移植する場合）

| 項目 | 値 |
|---|---|
| name_ja | ダナン |
| name_en | DA NANG |
| slug | danang |
| region | asia |
| country | ベトナム |
| description | 日本からの直行便もありアクセス抜群のダナン。透き通るビーチやランタンが輝くホイアンなど多彩なロケーションでの撮影が、リーズナブルに叶うのが魅力です。 |
| flight_time | 直行便で約5時間半 |
| time_difference | 2時間 |
| plans | ダナンビーチプラン、ダナンビーチ＆市内フォトプラン（ダブルカメラマン）などのProductを選択 |

## 地域一覧ページ（8ページ、最初の1回だけ作成）

STEP2の表のURLハンドルで、テーマテンプレート `page.region` を割り当てた
Pageを8枚作成してください。中身は空でも、`shop.metaobjects.destination`
から該当地域のデータを自動的に集めて一覧表示します。

## 撮影地一覧ページ（1件だけ）

タイトル「撮影地一覧」、URLハンドル `destinations`、テーマテンプレート
`page.destinations` でPageを1枚作成してください。
