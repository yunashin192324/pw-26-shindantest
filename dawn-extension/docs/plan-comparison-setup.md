# プラン比較表 用メタフィールドの追加手順

`destination-plan-compare.liquid`（都市ページの「プラン比較」セクション、
`page.destination.json`に追加済み）を動かすために、商品側に以下の
メタフィールドを追加してください。**すべて任意**です。未入力の項目は
表の中で「-」と表示されるだけで、表自体は崩れません。

設定 →「メタフィールド」→「商品」→「定義を追加」から、以下を1つずつ
作成してください（タイプはすべて**単一行テキスト**、名前空間は`custom`）。

| フィールド名 | キー (Key) | 入力例 |
|---|---|---|
| データ数 | `compare_data_count` | 150カット |
| ドレス | `compare_dress` | 1着レンタル込み |
| ヘアメイク | `compare_hair_makeup` | 込み |
| 撮影時間 | `compare_shooting_hours` | 3時間 |
| ロケ数 | `compare_location_count` | 2ヶ所 |
| 送迎 | `compare_transfer` | あり |
| 日本語アシスタント | `compare_japanese_assistant` | 同行あり |

数値専用の型にしていないのは、プランによって単位や書き方が微妙に違う
（「約150カット」「3〜4時間」等）ケースにそのまま対応できるようにする
ためです。

価格だけは商品自体の価格をそのまま使うので、この設定は不要です。

## 表示される条件

- その都市の`plans`欄（Destinationの商品参照リスト）に**2件以上**の
  プランが設定されている都市ページにだけ表示されます（1件だけでは
  比較にならないため）。
- 従来の「セクションのブロックにプランを1つずつ追加する」旧方式
  （現状ハワイのみ）には対応していません。比較表を使いたい場合は、
  先にそのプランを`plans`欄を使う新方式に移行してください
  （`docs/handover.md`の該当箇所を参照）。

## メタフィールドの入力場所

各商品（プラン）の編集画面 → 下の方にある「メタフィールド」欄 →
上記7項目が並んでいるので、そのプランに当てはまる内容を入力してください。
