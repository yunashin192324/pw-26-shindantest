# dawn-extension — 商品ページのProduct化（既存Dawnテーマへの追加分のみ）

前回お送りしたzip（独自theme.liquid一式）は**使いません**。実際のストアが
素のDawn＋カスタムセクション方式だったため、方針を変更し、**既存の実装は
そのまま**に、予約日時選択アプリ（カレンダー予約アプリ）を使うために
Product化が必須な「プランページ」だけを新規に用意しました。

## 結論：これだけ追加すればOKです

| ファイル | 置き場所（テーマのコードエディタ） |
| --- | --- |
| `sections/product-plan.liquid` | Sections フォルダに追加 |
| `templates/product.json` | Templates フォルダに追加 |

他のファイル（ドレスLP、コレクションLP、エリアLP、FAQ、お問い合わせ、
特定商取引法ページ、`collections/dress-wedding`）は**一切変更していません**。
今回のzipには含まれていません。

## なぜProduct化が必要か

予約日時選択アプリは「選んだ日時をカートに追加 → Shopify標準チェック
アウトで決済」という仕組みで動きます（アプリ名は失念とのことでしたが、
Appointoなど大半の予約アプリはこの方式です）。Shopifyの**Page**は
カート/チェックアウトと直接つながらないため、**Product**でないと
この仕組みが機能しません。カート・チェックアウト自体はDawn標準機能が
そのまま使えるので、新たに作る必要はありません。

`product-plan.liquid` は「予約（価格パネル）」部分を本物の
`{% raw %}{% form 'product', product %}{% endraw %}` で実装しており、
予約アプリのブロックはTheme Editorの「ブロックを追加 → アプリ」から
このフォームの内側に追加されます（選んだ日時がカート追加と同時に
line item propertyとして渡される構造）。

## 既存の実装との関係（重要）

`product-plan.liquid` は、いただいた `danang-beach-plan`（Page用の1回
限りのセクション）と**同じ見た目・同じブロック語彙**
（gallery_image / tag / option / schedule / faq / note）を踏襲した、
**再利用可能な商品セクション**です。プランごとに専用セクションを都度
作るのではなく、Product 1件＝Admin側で「テーマテンプレートを複製」
するだけで量産できます（後述）。

デザイン面もTailwind CDN + Dawnのテーマ変数（`--font-heading-family`
等）という、いただいたコードと同じ技術構成で作っています。ゴールド
`#B8860B` / アイボリー `#FAF8F5` も揃えています。

## 使い方（ダナン ビーチプランを例に）

1. **Admin → 商品 → 商品を追加**
   - 商品名：「ダナン ビーチプラン」
   - 価格：¥111,000（バリアントに設定）
   - タグ：`即予約`　← このタグの有無で予約パネルの表示が「即予約」
     ⇄「リクエスト予約」に自動で切り替わります（現在のFAQの説明文
     「即予約できます／現地確認後ご回答」と対応させています）
   - 商品説明：概要文（`overview_desc` を空欄にした場合のフォールバック
     として使われます）
2. その商品の「テーマ テンプレート」で `product` を選択
3. Theme Editorでこの商品ページを開き、内容を確認・調整
   （`templates/product.json` に、danang-beachphoto.jsonの内容を
   **正しいダナンの文言に修正した状態**で初期値を入れてあります —
   元データはヒーロー文言が「ロンドン フォトウェディング」になって
   いましたが、他の内容は全てダナンだったため、コピペミスと判断し
   修正しています）
4. 別プラン（ハワイ、ロンドン等）を作る場合は、Adminの「テーマ
   テンプレート」ドロップダウン →「新しいテンプレートを作成」→
   「他のテンプレートからコピー」で `product` を複製すれば、コード
   変更なしで量産できます
5. 予約アプリを導入したら、「予約（Reserve）」セクション →
   「ブロックを追加」→「アプリ」から追加
