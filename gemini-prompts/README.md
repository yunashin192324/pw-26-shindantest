# Gemini カスタム指示プロンプト

`HIS-wedding-section-builder.txt` は、HISウェディングのセクションHTMLをGemini（Gem）に対話生成させるためのカスタム指示です。Geminiのカスタムgemの「指示」欄にこの内容を貼り付けて使用します。

## 2026-08-31 改修内容（途中ループ・空回答の対策）

元の指示文で以下の問題があり、Geminiが途中でループしたり空回答になることがありました。

1. **分割ルールの二重管理**：「40行を超えたら分割」ルールと「文字数上限に達したら分割」ルールが並存し、しかも「40行」をモデル自身が正確に自己カウントするのは困難だった。
   → ユーザーが回答した件数（N）というモデルが確実に把握している数値だけで分割要否を判断する、単一のルールに統合。
2. **合言葉の完全一致待ち**：「OK」「続き」という文言に厳密一致しないと次に進めない設計だった。
   → 「続行の意思が読み取れる返信」であれば進めるよう緩和。
3. **「検討しすぎると空回答になる」という警告的な指示**：モデルに不要な緊張を強いていた。
   → 単純に「転記作業として扱う」という肯定的な指示に変更。
4. **スクリプト統合ルールが「あとから遡って書き換えて再掲する」処理を要求**：現状8セクション中スクリプトを使うのは【7】MOVIEのみで、実質発生しない場面のために複雑な手順を毎回検討させていた。
   → 「最初に出力する時点でまとめて1回だけ出力する」という前向き（プロアクティブ）な処理に単純化。
5. **冒頭の説明文と「セクションごとに逐次出力せよ」というルールの矛盾**：全部質問してから生成、とも読める記述だった。
   → 冒頭の説明文を逐次出力ルールと一致させて矛盾を解消。

改善後もGeminiの挙動に不具合が出る場合は、症状（どのセクションで／何ターン目で発生するか）を添えて共有してください。
