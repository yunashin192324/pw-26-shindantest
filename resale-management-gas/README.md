# 46期リセール管理システム（未成約ダッシュボード）

添付いただいた「46期リセール管理システム」一式をベースに、以下2点を追加した版です。
ベースの機能・画面構成・データ構造は変更していません。

## 今回追加した内容

### 1. 店舗分析ダッシュボードに分析項目を2つ追加

- **種別**（Ciao／imp／AirZ・DP／PEXなど、新規相談登録時の「種別」選択肢）別の内訳グラフ
- **出発年月**別の内訳グラフ

いずれも、既存の「都市コード別」「接客方法別」「旅行目的(小)別」と同じ形式（棒＝未成約数、
折れ線＝リセール継続率(%)、件数上位10区分を表示）です。既存の汎用グラフ描画関数
（`renderBreakdownChart`）をそのまま呼び出しているだけなので、集計ロジックや表示形式は
既存3グラフと完全に同一です。

### 2. リセールリスト一覧表に「出発年月」列を追加

- 表の一番右（「接客方法」列の隣）に追加しました。
- 表示はCSV由来の値をそのまま表示する参照専用列です（他の都市コード・種別等の列と同じ扱いで、
  編集はできません）。
- 見出しをクリックすると並べ替えできます（既存の並べ替え機能がそのまま使えます）。

## 変更したファイル

- `Index.html`：分析ダッシュボードのグラフ2枚分の入れ物（`<canvas>`）と、
  一覧表の見出し列（`<th>`）を追加。
- `Javascript.html`：追加したグラフを描画する呼び出し2行と、一覧表の行データに
  「出発年月」セル（`<td>`）を追加する1行を追加。

`Code.gs` / `InitSheet.gs` は変更していません。「種別」「出発年月」はもともとシートに
保存されており、画面へ送るデータ（`getDashboardData()`）にも既に含まれていたため、
バックエンド側の変更は不要でした。

## 導入方法

添付いただいた元のシステムと同じ手順です（`はじめにお読みください.txt` を参照）。
既に運用中のスプレッドシートがある場合は、Apps Scriptエディタで `Index.html` と
`Javascript.html` の中身をこのフォルダの内容に貼り替えて保存し、
**デプロイを管理 → 対象デプロイの鉛筆マーク → バージョン：新バージョン → デプロイ**
まで行うと反映されます（`Code.gs` は変更していないため貼り替え不要です）。
