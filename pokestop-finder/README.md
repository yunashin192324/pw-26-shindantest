# ストップ候補さがし

S2セルを指定して「候補を探す」を押すだけで、公開地図データからポケストップ候補を集め、申請文（タイトル・説明文・補助文）の下書きまで作るアプリです。

- 利用料なし・登録なし・APIキーなし
- データ（候補・申請文・確認状況）は使っている端末のブラウザにだけ保存されます
- 申請の送信はしません。文章をコピーして公式の申請画面で使ってください

## 使い方

1. セルID（例 `60188bf6dc` や数字のID）か緯度・経度を貼り付ける。地図をタップしてもよい
2. 「候補を探す」を押す
3. 候補カードの「申請文を作る」を押し、文章を確認・編集してコピーする

## 開き方

- インターネット上: GitHub Pages で `…/pokestop-finder/` を開く（main に取り込まれたあと）
- 手元: このフォルダの `index.html` をブラウザで開く。地図画像と候補の検索にはインターネット接続が必要です

## 使っている無料サービス

| 用途 | サービス | 送る内容 |
|---|---|---|
| 候補の検索 | OpenStreetMap（Overpass API） | 検索範囲の座標 |
| 補足情報 | Wikipedia 日本語版・Wikidata | 検索範囲の座標 |
| 地名 | OpenStreetMap Nominatim | セル中心の座標 |
| 地図画像 | OpenStreetMap タイル | 表示範囲 |

どれも無料の公開サーバーなので、混雑や利用制限で失敗することがあります。失敗時に自動で何度も再試行することはなく、同じセルの再取得は1分あける仕組みです。有料サービスへの自動切り替えはしません。

## 制約

- 公開地図データに登録されていない物は見つかりません。結果は「すべての候補」ではありません
- 既存のポケストップ・ジムの公開データはないため、必要なら地図の「既存スポット登録」で手動登録します
- 申請基準に関する判定は、公式基準の要旨と利用者間で知られている傾向（L17セル・20m）に基づく目安です
- 文字数の上限は公式の申請画面で確認してください

## 開発者向け

```
npm install          # 開発用の道具（S2ライブラリの再生成・テスト）だけ。アプリの利用には不要
npm test             # 部品のテスト（Node）
npm run e2e          # 画面の通しテスト（Playwright + Chromium。外部通信は架空データに差し替え）
npm run build:s2     # vendor/s2/s2.bundle.js を s2js から再生成
```

構成: `js/core/`（セル計算・データ取得・候補評価・文章生成・保存）、`js/app.js`（画面）、`vendor/`（Leaflet 1.9.4、s2js 1.44.0 を同梱）。
`tests/fixtures/sample.json` は各サービスの応答形式に合わせた架空データです。
