# 営業セールスダッシュボード セットアップガイド

このガイドだけを読めば、ゼロからWebアプリを動かせるようにまとめています。
（詳しい仕様や各機能の説明は `README.md` を参照してください。こちらは「導入」だけに絞った手順書です。）

---

## 0. 全体の構成（最初に知っておくこと）

このアプリは以下の2つに分かれています。

| 種類 | 何をするものか | 必要なもの |
|---|---|---|
| **本体アプリ**（Code.gs / InitSheet.gs / Index.html / Javascript.html / appsscript.json） | 実際にデータを保存・編集する本番用Webアプリ | Googleスプレッドシート、Google Apps Script |
| **モックアップ**（mockup/index.html、mockup/index-mobile.html） | サンプルデータでUI・操作感だけを確認する単体HTML | ブラウザだけ（ネット接続・Googleアカウント不要） |

まずはモックアップをブラウザで開くだけで見た目・操作感を確認でき、本番運用には本体アプリのセットアップが必要です。

---

## 1. モックアップだけを見たい場合（一番簡単）

1. ZIP を展開する。
2. `mockup/index.html`（PC用）または `mockup/index-mobile.html`（スマホ用）を、そのままダブルクリックしてブラウザで開く。
3. これだけで動きます。サンプルデータが自動で入っており、保存やCSVインポートなどの操作もすべてブラウザの中だけで完結します（サーバーには一切送信されません＝リロードすると入力内容は消えます）。

**注意：** ファイルを更新した場合は、開いているタブを一度すべて閉じてから、ダウンロードし直したファイルを開き直してください。ブラウザにキャッシュが残っていると、古い見た目のまま表示されることがあります（プライベートウィンドウ／シークレットウィンドウで開くと確実です）。

## 2. 本体アプリのセットアップ（本番用）

### 事前準備
- Googleアカウント（会社の業務用アカウントなど、実データを扱ってよい権限のもの）

### 手順

1. **新しいGoogleスプレッドシートを作成する**
   このスプレッドシートがそのままデータベースになります。実データを入れるため、共有設定は業務データに準じた権限にしてください。

2. スプレッドシートのメニューから **拡張機能 → Apps Script** を開く。

3. 左側にデフォルトで作られている `コード.gs`（または `Code.gs`）の中身をすべて削除し、ZIP内の **`Code.gs`** の内容をそのまま貼り付けて保存する（Ctrl+S / Cmd+S）。

4. 左側の「＋」ボタン →「スクリプト」を選び、ファイル名を `InitSheet` にする。中身に ZIP内の **`InitSheet.gs`** の内容を貼り付けて保存する（拡張子 `.gs` は自動で付きます）。

5. 左側の「＋」ボタン →「HTML」を選び、以下の2つを作成する。
   - ファイル名 `Index` → ZIP内の **`Index.html`** の内容を貼り付け
   - ファイル名 `Javascript` → ZIP内の **`Javascript.html`** の内容を貼り付け

   ※ ファイル名は `Index` と `Javascript` から変更しないでください（コード内でこの名前を参照しています）。

6. 左側の歯車アイコン（プロジェクトの設定）を開き、「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れる。
   すると左側に `appsscript.json` が表示されるので、中身を ZIP内の **`appsscript.json`** の内容に置き換える。
   （`access`（アクセス範囲）の値は、社内限定にするか等、運用に合わせて調整してください。）

7. 一度スプレッドシートのタブに戻り、リロードする。スプレッドシートのメニューに
   **「営業セールスダッシュボード」** という項目が追加されていることを確認する。
   （初回は権限の承認画面が出ることがあります。内容を確認し、許可してください。）

8. メニュー **「営業セールスダッシュボード」→「① 初期セットアップ（シート作成）」** を実行する。
   `予約データ` シート、`スタッフ権限` シート、`担当者マスタ` シートが自動で作られます。

9. **「スタッフ権限」シートを開き、自分自身のGoogleアカウントを「マスタ権限」で1行登録する。**
   ⚠️ ここを忘れると、後で他のメンバーに共有した際に全員がマスタ権限として扱われてしまいます。必ず最初に行ってください。

10. Apps Scriptエディタの右上 **デプロイ → 新しいデプロイ** をクリックする。
    - 種類の選択：歯車アイコンから **「ウェブアプリ」** を選ぶ
    - 実行ユーザー：**自分**
    - アクセスできるユーザー：運用方針に合わせて選択（社内のみ／全員など）
    - 「デプロイ」をクリックすると **ウェブアプリのURL** が発行されるので、これを利用者に共有する。

11. 発行されたURLを開き、「データ管理」タブの **CSVインポート**（マスタ権限のみ表示）から営業日報CSVを取り込む。

12. 他のメンバーを追加する場合は、Webアプリの「データ管理」タブ →「権限管理（スタッフ権限）」から、
    Googleアカウント・所属店舗・所属エリア・権限を登録する（マスタ権限のユーザーのみ操作できます）。

これで本番用のセットアップは完了です。

## 3. ★重要：コードを修正した後、画面に反映されない場合

Google Apps Script（GAS）は、**エディタで保存しただけでは、公開中のWebアプリには反映されません。**
「コードを直したのに画面が変わらない」という場合は、ほぼ必ずこれが原因です。

反映させるには、以下の手順が必要です。

1. Apps Scriptエディタの右上 **デプロイ → デプロイを管理** を開く。
2. 対象のデプロイの行にある **鉛筆マーク（編集）** をクリックする。
3. 「バージョン」の項目を **「新バージョン」** に変更する。
4. **「デプロイ」** ボタンを押す。

この操作をして初めて、公開URLの内容が最新のコードに更新されます。
（URLは変わりません。同じURLのまま中身だけが更新されます。）

**モックアップ（mockup/ 配下のHTML）にはこの概念はありません。** モックアップはただのHTMLファイルなので、ファイルを保存してブラウザで開き直すだけで最新の内容になります。それでも変わらない場合は、上記「1. モックアップだけを見たい場合」の注意書き（キャッシュ・タブの閉じ直し）を確認してください。

## 4. ファイル構成

```
reservation-dashboard-gas/
├─ SETUP_GUIDE.md     … このセットアップガイド
├─ README.md          … 全機能の詳細説明（仕様書）
├─ appsscript.json    … GASプロジェクトのマニフェスト（タイムゾーン・Webアプリ設定）
├─ Code.gs            … バックエンドAPI（doGet、CSVインポート、データ管理）
├─ InitSheet.gs       … シート初期化（メニュー実行）
├─ Index.html         … 画面のHTML構造
├─ Javascript.html    … 画面のロジック（フィルタ・集計・グラフ描画）
└─ mockup/
   ├─ index.html        … オフラインで見られるPC版モックアップ
   └─ index-mobile.html … オフラインで見られるスマホ版モックアップ
```

## 5. よくあるつまずきポイント

| 症状 | 原因・対処 |
|---|---|
| Webアプリを開くとメニューがない／エラーになる | 手順8の初期セットアップを実行していない可能性があります。 |
| コードを直したのに本番の画面が変わらない | 上記「3. ★重要」を参照。新バージョンでの再デプロイが必要です。 |
| モックアップの表示が古いまま／挙動がおかしい | ブラウザのキャッシュか、古いファイルを開いている可能性があります。タブをすべて閉じ、ファイルを開き直す（プライベートウィンドウ推奨）。 |
| 自分だけ権限がない・操作できない | 「スタッフ権限」シートに自分のアカウントが「マスタ権限」で登録されているか確認してください（手順9）。 |
| CSVを取り込んでも何も増えない | 見出し行が19項目のうち半分以上一致しないと自動検出できません。文字コードがUTF-8になっているかも確認してください（README.mdの「CSVインポートの仕様」参照）。 |
