# 予約データ分析ダッシュボード（Googleスプレッドシート + GAS）

営業日報CSVのうち、以下19項目だけを抽出して蓄積し、分析するダッシュボードです。
Googleスプレッドシートと Google Apps Script（GAS）のみで構築しており、Webアプリとして利用します。
UI/UX は添付いただいた「46期リセール管理システム」の配色・レイアウト（ヘッダーのKPIカード、タブ切り替え、
固定見出しの一覧表、モーダル、トースト通知など）を踏襲しています。

## 抽出対象の19項目

| CSV列番号 | 項目名 |
|---|---|
| 006 | エリア |
| 007 | 営業所 |
| 013 | 最終目的地 |
| 014 | 予約日 |
| 016 | 出発予定日 |
| 019 | 顧客ID |
| 020 | 予約番号 |
| 023 | 性別 |
| 024 | 国籍 |
| 029 | 商品分類 |
| 031 | キャリア |
| 037 | ツアーブランド区分 |
| 038 | ツアーコード |
| 046 | 売上(商品請求金額) |
| 047 | 入金額 |
| 051 | STS |
| 058 | 担当者 |
| 070 | 商品タイトル |
| 076 | 旅行日数 |

CSVの見出しが `006:エリア` のように「列番号：項目名」の形式であれば、列の並び順が変わっても
項目名だけで自動的に列を判定して取り込みます。上記以外の列（69項目分）は取り込み時に読み捨てます。

## 現場で入力する項目（CSVには無く、画面から直接入力する）

CSV由来19項目に加えて、「予約データ」シートの20〜29列目に以下10項目を追加しています。
これらはCSVインポート時は空欄のまま追加され、Webアプリの「予約データ一覧」タブから直接入力・編集します。

| 項目 | 内容 |
|---|---|
| CHK日 | 日付を直接入力 |
| 保険 / 保険数量 | 〇・✖・－（既定値）を選択。〇のときだけ数量（加入PAX数）を入力できる |
| Wifi / Wifi数量 | 同上（数量＝販売台数） |
| TAViCA / TAViCA数量 | 同上（数量＝加入数） |
| キャンサポ / キャンサポ数量 | 同上（数量＝加入PAX数） |
| メモ | 自由記述 |

保険・Wifi・TAViCA・キャンサポのステータスを「〇」以外に変更すると、対応する数量は自動で空欄に戻ります。

## 権限（スタッフ権限シート）

初期セットアップを実行すると、データ用の「予約データ」シートに加えて「スタッフ権限」シートも作成されます。
列は `Googleアカウント・氏名・所属店舗・所属エリア・権限` の5列で、権限は次の3段階です。

| 権限 | 閲覧範囲 | CSVインポート |
|---|---|---|
| 社員 | 自分の「所属店舗」と一致する営業所の行のみ | 不可 |
| 所長・チーフ | 自分の「所属エリア」と一致するエリアの行のみ | 不可 |
| マスタ権限 | 全エリア | 可能（重複削除・全削除・権限管理も可能） |

**「スタッフ権限」シートに1件も登録が無い間は、誰でもマスタ権限として扱われます**（最初のセットアップができるようにするための仕様です）。
運用を始める前に、必ず自分自身のGoogleアカウントを「マスタ権限」で1行登録してください。
登録が無いままの状態で他のメンバーに共有すると、全員がマスタ権限として全データを閲覧・操作できてしまいます。

スタッフ権限シートに登録済みでもいずれの権限にも一致しないアカウント（メールアドレスが1件も無い等）でアクセスすると、
「アクセス権がありません」という案内が表示され、データは一切表示されません。

Webアプリからも、「データ管理」タブの「権限管理（スタッフ権限）」からアカウントの追加・編集・削除ができます
（マスタ権限のユーザーのみ操作できます）。

## 予約データ一覧の列の並び順

「予約データ一覧」タブの列は、初期状態では以下の順です（ご指定いただいた並び順をもとにしています）。

```
CHK日 → 予約番号 → 担当者 → 出発予定日 → 保険 → Wifi → TAViCA(TVC) → キャンサポ →
営業所 → 最終目的地 → 商品分類 → ツアーブランド区分 → ツアーコード → キャリア →
売上(商品請求金額) → 入金額 → STS → 商品タイトル → 旅行日数 → 予約日 → メモ
```

※「営業所」「メモ」の2項目は、ご指定いただいた並び順リストに含まれていなかったため、
　こちらの判断で上記の位置に補って表示しています（営業所は担当者に関連する情報として付帯商品の直後に、
　メモは自由記述のため末尾に配置）。ご希望の位置と違う場合は、次段落の並び替え機能でいつでも調整できます。

「データ管理」タブの「予約データ一覧の列の並び順」から、▲▼ボタンで並び替えて保存できます
（どの権限のユーザーでも並び替えできます）。保存するとスプレッドシート単位で記録され、
他のメンバーがWebアプリを開いたときにも同じ並び順で表示されます。
「エリア」「顧客ID」「国籍」「性別」の4項目は、ご指定に従って一覧表からは削除しています
（絞り込み検索や個人別サマリーでは引き続き使用します）。

## ダッシュボードのフィルタ（タブごとに別々です）

- **分析ダッシュボードタブ**：エリア・営業所・商品分類・基準日（予約日／出発予定日）・期間（From〜To）
- **予約データ一覧タブ**：エリア・店舗（営業所）・担当者・出発予定日（From〜To）・キーワード検索

ヘッダーのKPIカードと分析ダッシュボードのグラフ・ランキングは、分析ダッシュボードタブのフィルタに連動します。

## 個人別サマリータブ

担当者（営業所×担当者）ごとに、記録件数と保険・Wifi・TAViCA・キャンサポの数量合計を集計して一覧表示します。
あなたが閲覧できる範囲（権限による絞り込み後）のデータが対象です。営業所名・担当者名で検索できます。

## ファイル構成

```
reservation-dashboard-gas/
├─ appsscript.json   … GASプロジェクトのマニフェスト（タイムゾーン・Webアプリ設定）
├─ Code.gs           … バックエンドAPI（doGet、CSVインポート、データ管理）
├─ InitSheet.gs       … シート初期化（メニュー実行）
├─ Index.html         … 画面のHTML構造
├─ Javascript.html    … 画面のロジック（フィルタ・集計・グラフ描画）
└─ mockup/index.html … オフラインPCでも開けるUI/UXモックアップ（後述）
```

## 導入手順

1. **新しいGoogleスプレッドシートを作成する**
   （このスプレッドシートがそのままデータベースになります。実データを入れるので、
   共有設定は業務で扱う顧客データに準じた権限にしてください。）

2. **拡張機能 → Apps Script** を開く。

3. デフォルトで作られている `コード.gs`（または `Code.gs`）の中身を全て削除し、
   このフォルダの `Code.gs` の内容を貼り付けて保存する。

4. 左側の「＋」から **スクリプト** を追加し、ファイル名を `InitSheet` にして
   `InitSheet.gs` の内容を貼り付ける（拡張子 `.gs` は自動で付きます）。

5. 同様に **HTML** ファイルを2つ追加する。
   - ファイル名 `Index` → `Index.html` の内容を貼り付け
   - ファイル名 `Javascript` → `Javascript.html` の内容を貼り付け

6. プロジェクトの設定（歯車アイコン）で「`appsscript.json` マニフェスト ファイルをエディタで表示する」
   にチェックを入れ、`appsscript.json` の中身をこのフォルダの `appsscript.json` の内容に置き換える
   （Webアプリのアクセス範囲 `access` は組織の運用に合わせて `DOMAIN` / `ANYONE` などに調整してください）。

7. 保存したら、一度スプレッドシートのタブを開き直す（またはApps Scriptエディタで `onOpen` を
   一度実行して権限を承認する）。スプレッドシートのメニューに **「予約データダッシュボード」** が追加されます。

8. メニュー **「予約データダッシュボード」→「① 初期セットアップ（シート作成）」** を実行する。
   `予約データ` シート（29列・見出し付き）と `スタッフ権限` シートが作成されます。
   ※ Webアプリ側の「初期セットアップを実行する」ボタンからも同じ処理を実行できます。

9. **「スタッフ権限」シートに、自分自身のGoogleアカウントを「マスタ権限」で1行登録する。**
   （これを忘れると、他のメンバーに共有した際に全員がマスタ権限として扱われてしまいます。）

10. Apps Scriptエディタの **デプロイ → 新しいデプロイ** を実行する。
    - 種類：**ウェブアプリ**
    - 実行ユーザー：**自分**
    - アクセスできるユーザー：組織の運用に合わせて選択
    - デプロイ後に表示される **ウェブアプリのURL** を利用者に共有する。

11. Webアプリを開き、「予約データ一覧」タブの **CSVインポート**（マスタ権限のみ表示）から営業日報CSVを取り込む。

12. 他のメンバーを追加するときは、Webアプリの「データ管理」タブ →「権限管理（スタッフ権限）」から
    Googleアカウント・所属店舗・所属エリア・権限を登録する（マスタ権限のユーザーのみ操作できます）。

## Code.gs を修正したときの再デプロイ

Apps Scriptは保存しただけでは公開中のWebアプリに反映されません。**デプロイを管理 → 対象のデプロイの
鉛筆マーク → バージョン：新バージョン → デプロイ** まで行って初めて反映されます。

## CSVインポートの仕様

- `Utilities.parseCsv` でCSVを解析するため、ダブルクォートで囲まれたセル内のカンマ・改行にも対応しています。
- 文字コードは **UTF-8（BOM付き可）** を想定しています。Shift_JIS等の場合は、事前にUTF-8で保存し直してください。
- 見出し行は先頭5行の中から自動検出します（19項目のうち半分以上が一致した行を見出し行とみなします）。
- 19項目すべての値が完全に一致する行は「重複」として取り込まずスキップします。
  行の一部だけが違う場合（例：入金額だけ更新された等）は別行として追加されるため、
  必要に応じて「データ管理」タブの重複削除・全削除をご利用ください。
- `顧客ID` `予約番号` など先頭0を含みうる項目は、シート上で文字列（表示形式 `@`）として保存し、
  桁落ちしないようにしています。

## 実データの取り扱いについて（重要）

このリポジトリには、動作確認に使った実際の営業日報CSV（顧客ID・予約番号・担当者コードなどを含む）は
含めていません。取り込むCSVファイル自体もこのリポジトリには置かず、各自の権限管理下にあるGoogleドライブ /
スプレッドシートのみで扱ってください。`mockup/` 配下のサンプルデータもすべて架空の値です。

## オフラインでのUI/UX確認（モックアップ：PC版・スマホ版）

`mockup/` には、インターネット接続もGoogleアカウントも不要な**単体HTMLファイル**を2つ用意しています。
どちらもTailwind CDNやChart.jsなどの外部CDNを一切使わず、CSS・グラフ描画・架空のサンプルデータを
すべてファイル内に埋め込んでいるため、ダブルクリックしてブラウザで開くだけでオフラインでも確認できます
（実際のスプレッドシートとは接続されていない見た目確認専用のモックアップです）。

| ファイル | 対象 | 画面構成 |
|---|---|---|
| `mockup/index.html` | PC・タブレット | 上部タブ切り替え、複数列フィルタ、表形式の一覧・ランキング |
| `mockup/index-mobile.html` | スマートフォン | 下部タブバー、折りたたみ式フィルタ、1件ずつのカード表示、横スクロール無し |

どちらもCHK日・保険/Wifi/TAViCA/キャンサポ・メモの入力、個人別サマリー、列の並び替えを操作でき、
ヘッダーの「表示権限を切替」から社員／所長・チーフ／マスタ権限それぞれの見え方
（閲覧できる件数の違い、CSVインポート・データ管理操作の表示/非表示）を切り替えて確認できます。
業務ロジック・サンプルデータは2つのファイルで共通で、画面のレイアウトのみ利用端末に合わせて変えています。
